# Book
Book is a simple console-base library management system made in c++.

![Book](https://cdn.hackclub.com/01a0ca70-b6de-747a-b03f-fc77bfafb73c/image.png)

## What does it do?
Book lets you manage a small library directly from the console. You can register books with their code, title, author, category, year and price. You can also list the books in the libray and generate reports.

Everything is handle through a simple menu, so you can keep your library organized without getting lost between endless shelves.

## How to use it?
1. Go to the Releases section of this repository
2. Download the .exe file.
3. Open the program.

That's it. Your little library is ready to go.
